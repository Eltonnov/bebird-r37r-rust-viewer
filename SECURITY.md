# Security and privacy

- Bebird camera Wi-Fi is commonly unencrypted. Do not use this on public or untrusted networks.
- The viewer only communicates with the local camera using UDP; it performs no cloud upload.
- Only connect to cameras you own or are authorized to use.
- `Aufnahmen/` contains private images and is intentionally gitignored.
- Never commit vendor APKs, reverse-engineered source dumps, identifiers, packet captures, personal screenshots, access tokens, or local logs.
- Please use private maintainer contact for a security report rather than a public issue with secrets.
- No guarantee of medical suitability or safety. This is a hobbyist viewer, not a certified medical device.
